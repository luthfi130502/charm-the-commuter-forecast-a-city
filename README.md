## The forecast

> Puddlewick: rain again today, falling upward as usual — commuters are reminded to carry their umbrellas upside down and arrive dry.

One line, 131 characters, in the flat register of a real weather forecast —
for Puddlewick, a city where the rain falls up, so the only sensible advice
is to flip your umbrella and walk to work dry.

## Run it

```sh
python3 main.py
```

This writes the forecast line to `/output/entry.txt` (UTF-8, single line).
The script asserts the bounty gate before writing: 1–140 characters, not
only whitespace, exactly one line.
